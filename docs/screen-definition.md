## SCR-001 로그인

| 항목      | 내용                                           |
| --------- | ---------------------------------------------- |
| 화면 ID   | SCR-001                                        |
| 화면명    | 로그인                                         |
| URL       | `/login`                                       |
| 접근 권한 | 전체 (미인증)                                  |
| 목적      | 이메일과 비밀번호로 인증하여 시스템에 진입한다 |

### 레이아웃

```
┌─────────────────────────────────┐
│         영업 일일 보고 시스템        │
│                                 │
│  이메일 [________________]      │
│  비밀번호 [________________]    │
│                                 │
│         [ 로그인 ]              │
└─────────────────────────────────┘
```

### 구성 요소

| 컴포넌트    | 타입           | 필수 | 설명                 |
| ----------- | -------------- | ---- | -------------------- |
| 이메일      | text input     | Y    | 등록된 사용자 이메일 |
| 비밀번호    | password input | Y    | 비밀번호             |
| 로그인 버튼 | button         | —    | 인증 실행            |

### 액션

| 트리거           | 처리                          | 결과                                          |
| ---------------- | ----------------------------- | --------------------------------------------- |
| 로그인 버튼 클릭 | 이메일/비밀번호 인증 API 호출 | 성공 → SCR-002 이동 / 실패 → 에러 메시지 표시 |
| Enter 키         | 로그인 버튼과 동일            | 동일                                          |

### 유효성 검사

- 이메일: 필수, 이메일 형식
- 비밀번호: 필수
- 인증 실패 시 "이메일 또는 비밀번호가 올바르지 않습니다" 표시

## SCR-002 보고서 목록 (대시보드)

| 항목      | 내용                                                       |
| --------- | ---------------------------------------------------------- |
| 화면 ID   | SCR-002                                                    |
| 화면명    | 보고서 목록                                                |
| URL       | `/reports`                                                 |
| 접근 권한 | SALES, MANAGER                                             |
| 목적      | 보고서 목록을 검색·열람하고, 신규 보고서 작성으로 진입한다 |

### 레이아웃

```
┌─────────────────────────────────────────────────────┐
│ 영업 일일 보고 시스템          [사용자명] [로그아웃] │
├─────────────────────────────────────────────────────┤
│ 보고서 목록                    [ + 보고서 작성 ]    │
│                                                     │
│ 검색 조건                                           │
│ 기간: [____] ~ [____]  담당자: [________▼]  [검색] │
│                                                     │
│ ┌───┬────────┬────────┬──────────┬───────────────┐ │
│ │ # │ 날짜   │ 담당자 │ 방문건수 │ 작성일시       │ │
│ ├───┼────────┼────────┼──────────┼───────────────┤ │
│ │ 1 │ 04/13  │ 홍길동 │ 3건      │ 2026-04-13 ... │ │
│ │ 2 │ 04/12  │ 홍길동 │ 2건      │ 2026-04-12 ... │ │
│ └───┴────────┴────────┴──────────┴───────────────┘ │
│                     [< 1 2 3 >]                     │
└─────────────────────────────────────────────────────┘
```

### 구성 요소

| 컴포넌트         | 타입       | 설명                                     |
| ---------------- | ---------- | ---------------------------------------- |
| 기간 (시작)      | date input | 보고서 날짜 검색 시작일                  |
| 기간 (종료)      | date input | 보고서 날짜 검색 종료일                  |
| 담당자           | select     | MANAGER만 표시. 전체/영업사원 선택       |
| 검색 버튼        | button     | 조건 적용 후 목록 재조회                 |
| 보고서 작성 버튼 | button     | SCR-004 (신규 작성)로 이동. SALES만 표시 |
| 목록 행          | link       | 클릭 시 SCR-003으로 이동                 |
| 페이지네이션     | pager      | 페이지 이동                              |

### 액션

| 트리거           | 처리                                | 결과                  |
| ---------------- | ----------------------------------- | --------------------- |
| 화면 진입        | 기본 조건(최근 1개월)으로 목록 조회 | 목록 표시             |
| 검색 버튼 클릭   | 입력 조건으로 재조회                | 목록 갱신             |
| 행 클릭          | —                                   | SCR-003으로 이동      |
| 보고서 작성 버튼 | —                                   | SCR-004 (신규)로 이동 |

### 권한별 차이

| 항목             | SALES                  | MANAGER             |
| ---------------- | ---------------------- | ------------------- |
| 담당자 필터      | 표시 안 함 (본인 고정) | 전체 사원 선택 가능 |
| 보고서 작성 버튼 | 표시                   | 표시 안 함          |
| 조회 범위        | 본인 보고서만          | 전체 보고서         |

## SCR-003 보고서 상세 조회

| 항목      | 내용                                           |
| --------- | ---------------------------------------------- |
| 화면 ID   | SCR-003                                        |
| 화면명    | 보고서 상세 조회                               |
| URL       | `/reports/:report_id`                          |
| 접근 권한 | SALES (본인), MANAGER (전체)                   |
| 목적      | 보고서 내용을 열람하고, 상급자가 댓글을 남긴다 |

### 레이아웃

```
┌──────────────────────────────────────────────────────┐
│ [< 목록으로]        2026-04-13 홍길동 님 보고서       │
│                                          [편집] [삭제]│
├──────────────────────────────────────────────────────┤
│ ▌방문 기록                                           │
│ ┌──────────────┬──────────────────────────────────┐  │
│ │ 고객명       │ 방문 내용                         │  │
│ ├──────────────┼──────────────────────────────────┤  │
│ │ (주)삼성전자 │ 신규 제안서 제출 및 담당자 면담   │  │
│ │ (주)LG화학   │ 계약 갱신 협의                   │  │
│ └──────────────┴──────────────────────────────────┘  │
│                                                      │
│ ▌과제 / 상담 (Problem)                               │
│ ┌────────────────────────────────────────────────┐   │
│ │ 1. 삼성전자 견적 재검토 요청 대응 필요         │   │
│ │    💬 상급자 댓글: 견적팀에 확인 요청해 주세요 │   │
│ │              [댓글 입력창 (MANAGER만 표시)]     │   │
│ └────────────────────────────────────────────────┘   │
│                                                      │
│ ▌내일 할 일 (Plan)                                   │
│ ┌────────────────────────────────────────────────┐   │
│ │ 1. LG화학 계약서 초안 작성                     │   │
│ │    💬 상급자 댓글: 법무팀 검토 일정 확인 바람  │   │
│ │              [댓글 입력창 (MANAGER만 표시)]     │   │
│ └────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

### 구성 요소

| 컴포넌트         | 타입              | 설명                                               |
| ---------------- | ----------------- | -------------------------------------------------- |
| 목록으로 버튼    | link              | SCR-002로 복귀                                     |
| 편집 버튼        | button            | SCR-004 (편집)로 이동. 본인 보고서 SALES만 표시    |
| 삭제 버튼        | button            | 보고서 삭제 확인 후 처리. 본인 보고서 SALES만 표시 |
| 방문 기록 테이블 | table             | 고객명, 방문 내용 표시                             |
| Problem 목록     | list              | 각 항목 + 달린 댓글 표시                           |
| Plan 목록        | list              | 각 항목 + 달린 댓글 표시                           |
| 댓글 입력창      | textarea + button | MANAGER만 표시. 각 Problem/Plan 항목 하단          |

### 액션

| 트리거         | 처리                      | 결과                           |
| -------------- | ------------------------- | ------------------------------ |
| 편집 버튼      | —                         | SCR-004 (편집)로 이동          |
| 삭제 버튼      | 삭제 확인 다이얼로그 표시 | 확인 시 삭제 후 SCR-002로 이동 |
| 댓글 등록 버튼 | 댓글 저장 API 호출        | 댓글 목록 갱신                 |

### 권한별 차이

| 항목           | SALES              | MANAGER    |
| -------------- | ------------------ | ---------- |
| 편집/삭제 버튼 | 본인 보고서만 표시 | 표시 안 함 |
| 댓글 입력창    | 표시 안 함         | 표시       |

## SCR-004 보고서 작성/편집

| 항목      | 내용                                                 |
| --------- | ---------------------------------------------------- |
| 화면 ID   | SCR-004                                              |
| 화면명    | 보고서 작성/편집                                     |
| URL       | `/reports/new`, `/reports/:report_id/edit`           |
| 접근 권한 | SALES                                                |
| 목적      | 일일 보고서를 신규 작성하거나 기존 보고서를 수정한다 |

### 레이아웃

```
┌──────────────────────────────────────────────────────┐
│ [< 취소]          보고서 작성             [저장]      │
├──────────────────────────────────────────────────────┤
│ 보고 날짜: [2026-04-13]                              │
│                                                      │
│ ▌방문 기록                              [+ 행 추가] │
│ ┌──────────────────────┬───────────────────────────┐ │
│ │ 고객 [검색/선택 ▼]   │ 방문 내용 [____________]  │ │
│ │ 고객 [검색/선택 ▼]   │ 방문 내용 [____________]  │ │
│ └──────────────────────┴─────────────────── [🗑]───┘ │
│                                                      │
│ ▌과제 / 상담 (Problem)                  [+ 항목 추가]│
│ ┌─────────────────────────────────────────────────┐  │
│ │ [________________________________________] [🗑] │  │
│ │ [________________________________________] [🗑] │  │
│ └─────────────────────────────────────────────────┘  │
│                                                      │
│ ▌내일 할 일 (Plan)                      [+ 항목 추가]│
│ ┌─────────────────────────────────────────────────┐  │
│ │ [________________________________________] [🗑] │  │
│ └─────────────────────────────────────────────────┘  │
│                                                      │
│                              [취소]  [저장]          │
└──────────────────────────────────────────────────────┘
```

### 구성 요소

| 컴포넌트               | 타입               | 필수 | 설명                                   |
| ---------------------- | ------------------ | ---- | -------------------------------------- |
| 보고 날짜              | date input         | Y    | 기본값: 오늘. 신규 작성 시만 변경 가능 |
| 방문 기록 — 고객       | select (검색 포함) | Y    | 고객 마스터에서 선택                   |
| 방문 기록 — 방문 내용  | textarea           | Y    | 방문 내용 자유 입력                    |
| 방문 기록 행 추가 버튼 | button             | —    | 방문 기록 행 1개 추가                  |
| 방문 기록 행 삭제 버튼 | icon button        | —    | 해당 행 삭제                           |
| Problem 입력           | textarea           | N    | 과제/상담 내용 자유 입력               |
| Problem 항목 추가 버튼 | button             | —    | Problem 입력 행 1개 추가               |
| Problem 항목 삭제 버튼 | icon button        | —    | 해당 항목 삭제                         |
| Plan 입력              | textarea           | N    | 내일 할 일 자유 입력                   |
| Plan 항목 추가 버튼    | button             | —    | Plan 입력 행 1개 추가                  |
| Plan 항목 삭제 버튼    | icon button        | —    | 해당 항목 삭제                         |
| 저장 버튼              | button             | —    | 보고서 저장                            |
| 취소 버튼              | button             | —    | 편집 취소 후 이전 화면으로 복귀        |

### 액션

| 트리거            | 처리                                   | 결과                                  |
| ----------------- | -------------------------------------- | ------------------------------------- |
| 화면 진입 (신규)  | 날짜 기본값 오늘, 방문 기록 1행 초기화 | 빈 폼 표시                            |
| 화면 진입 (편집)  | 기존 보고서 데이터 로드                | 기존 내용 채워진 폼 표시              |
| 행/항목 추가 버튼 | 입력 행 동적 추가                      | 행 추가                               |
| 행/항목 삭제 버튼 | 해당 행 제거                           | 행 삭제                               |
| 고객 선택         | 고객 마스터 검색 팝업 또는 드롭다운    | 선택된 고객명 표시                    |
| 저장 버튼         | 유효성 검사 → 저장 API 호출            | 성공 시 SCR-003으로 이동              |
| 취소 버튼         | 변경사항 있을 경우 확인 다이얼로그     | 확인 시 SCR-002 또는 SCR-003으로 복귀 |

### 유효성 검사

- 보고 날짜: 필수
- 방문 기록: 최소 1행 이상. 고객 선택 및 방문 내용 모두 필수
- 동일 날짜 보고서 중복 등록 시 에러 메시지 표시: "해당 날짜의 보고서가 이미 존재합니다"

| 페이지네이션   | pager      | 페이지 이동                                                           |
